# agent-skills

`agent-skills` is a shared AI skills repository that developers and other AI users can refer to for practical, reusable
skills.

## Purpose

Use this repository to:

- collect useful AI skills in one place
- document clear, repeatable workflows
- share prompts, patterns, and examples that improve day-to-day AI-assisted work

## Skills list

| Skill                                                                                      | Description                                                                                                                                                                                                                                                                                    |
|--------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [`google-developer-style`](skills/google-developer-style/SKILL.md)                         | Writes and edits prose in the style of the Google Developer Documentation Style Guide: second person, active voice, sentence-case headings, inclusive language, and consistent formatting. Use for any writing or editing task, not just formal technical docs.                                |
| [`humanizer`](skills/humanizer/SKILL.md)                                                   | Removes signs of AI-generated writing from text, including stylistic tells (em dashes, rule-of-three, inflated vocabulary) and hidden technical watermarks. Use when editing, reviewing, or finalizing text an agent produced.                                                                 |
| [`obsidian-academic-notes-formatting`](skills/obsidian-academic-notes-formatting/SKILL.md) | Formats Obsidian academic vault notes for MSc Computing & AI coursework into a consistent structure: YAML frontmatter, heading hierarchy, callouts, wikilinks, tags, and file naming.                                                                                                          |
| [`obsidian-markdown-formatting`](skills/obsidian-markdown-formatting/SKILL.md)             | Covers Obsidian-flavored Markdown for any vault: basic formatting, callouts, wikilinks and embeds, block references, properties, tags, tables, and math, and where it differs from plain CommonMark.                                                                                           |
| [`pythonic-coder`](skills/pythonic-coder/SKILL.md)                                         | Writes, reviews, refactors, and tests idiomatic, maintainable Python, covering naming, function design, type hints, error handling, resource management, project structure, logging, and testing. Use for Python modules, scripts, libraries, services, data pipelines, CLIs, or code reviews. |
| [`skill-authoring`](skills/skill-authoring/SKILL.md)                                       | Helps write, review, or fix a SKILL.md file or agent skill folder so it's spec-compliant and reliably discoverable, covering frontmatter, progressive disclosure, and file structure.                                                                                                          |
